# 🛡️ Windfall Discord Bot

บอท Discord สำหรับจัดการระบบกิลด์และการอัปเดตสเตตัสตัวละครในเกม (ผูกกับฐานข้อมูล Firebase)

## 📋 การตั้งค่า (Configuration)
โปรเจกต์นี้แยกการตั้งค่าไว้ชัดเจน:
* **`.env`**: เก็บค่าสำหรับ **Production / Discloud** (ค่าเริ่มต้น)
* **`.env.dev`**: เก็บค่าสำหรับ **Development** บนเครื่องตัวเอง

---

## 🚀 วิธีการรันบอท (Commands)

### 1. เปิดใช้งานบอท (Start Bot)
```bash
# รันบนเครื่องตัวเอง (โหมด Development - โหลด .env.dev)
npm run start:dev

# รันโหมด Production (โหลด .env - ตัวเดียวกับที่ Discloud รัน)
npm start
```

### 2. อัปเดตเมนูคำสั่ง (Deploy Commands)
```bash
# อัปเดตขึ้นตัว Dev
npm run deploy:dev

# อัปเดตขึ้นตัว Production
npm run deploy
```

### 3. การใช้งานบน Discloud (Hosting)
บน Discloud ระบบจะรันคำสั่ง `npm start` (หรือ `node index.js`) ซึ่งจะอ่านค่าจาก **`.env` (Production)** และต่อฐานข้อมูล Production โดยอัตโนมัติ 100% เสมอ ไม่ต้องตั้งค่าอะไรเพิ่มเติมครับ

---

## 📁 โครงสร้างโปรเจกต์ที่สำคัญ (Architecture)

โปรเจกต์นี้ถูกจัดระเบียบใหม่เพื่อให้ดูแลรักษาง่ายที่สุด:

* **`/commands`**: เก็บไฟล์คำสั่ง Slash Commands ทั้งหมด (เช่น `/menu`, `/guild_stats`, `/update_stat`)
* **`/events`**: เก็บระบบรับเหตุการณ์ต่างๆ ของ Discord (เช่น ดักตอนบอทออนไลน์, ดักคนพิมพ์ข้อความ, ดักคนออกจากเซิร์ฟเวอร์)
* **`/interactions`**: ตัวจัดการเวลาคนกด UI ต่างๆ บน Discord โดยแยกเป็น 3 ส่วน:
  * `buttons.js`: จัดการตอนที่คนกด "ปุ่ม"
  * `modals.js`: จัดการตอนที่คนกด "Submit แบบฟอร์ม"
  * `selectMenus.js`: จัดการตอนที่คนเลือก "Dropdown เมนู"
* **`/services`**: ตัวเชื่อมต่อกับฐานข้อมูล
  * `memberService.js`: รวมคำสั่งที่ใช้ดึง/เพิ่ม/ลบ ข้อมูลสเตตัสสมาชิกกิลด์ใน Firebase ไว้ที่เดียว
* **`deploy-commands.js`**: สคริปต์เบื้องหลังที่คอยอัปเดตคำสั่งขึ้น Discord
* **`index.js`**: หัวใจหลักที่คอยโหลดโค้ดทุกส่วนและรับมือกับ Error ไม่ให้บอทดับ

---

## 🛡️ ระบบการจัดการ Error
ตัวบอทมีระบบป้องกันการพัง (Crash Protection) ฝังไว้ใน `index.js` หากโค้ดทำงานผิดพลาด บอทจะไม่ดับ แต่จะแจ้งเตือนข้อผิดพลาดนั้นไปที่ห้อง `DEV_LOG_CHANNEL_ID` ที่คุณตั้งค่าไว้ เพื่อให้คุณรู้ตัวและเข้ามาแก้โค้ดได้ทันที
